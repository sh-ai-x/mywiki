# Career Strategy

## Updated decision — September 8, 2026

Main target: **AI Agent Engineer / Applied AI Engineer with Python backend responsibilities**. Security and evaluation are the specialization. This is a judgment about continuity with your supplied work, not a measured ranking of hiring probabilities.

Map preparation to the supplied duties: prompt optimization, workflow topology/planning, component and end-to-end evaluation, benchmark generation and MCP integration. Build [AgentOps Workbench](../proposals/agentops-workbench-proposal.md), then connect its evidence to PipelineSentry. The [security alternatives](./08-security-and-ai-security-study-tracks.md) are separate choices, not additional prerequisites.

Start eligible applications after the first runnable vertical slice. Explain the career gap briefly and truthfully, then show dated recent releases, tests and personal contributions. A proposal is not implementation experience. Verify degree, student status, language and work authorization; a portfolio does not automatically waive the supplied degree requirement.

See the [career comparison and hiring evidence](./09-career-comparison-and-evidence.md) for the conditional SOC alternative and the higher combined preparation burden of specialist AI security.

The best-fit direction is:

- Primary: AI Engineer / Agentic AI Engineer
- Secondary: AI Backend / Platform Engineer
- Differentiator: Security, reliability, and observability for agentic systems

This is the most coherent story for the portfolio project you already have. The project is not just an API or a CRUD backend. It is about:

- agent workflows
- LangGraph / LangChain orchestration
- traceability and evaluation
- tool authorization
- prompt-injection and indirect-injection defenses
- replayable incident analysis

That maps better to agent engineering than to generic backend. Security should not be treated as a separate random track. It should be the specialization that makes the agent work credible in production.

## Recommendation

Focus your applications in this order:

1. AI Engineer
2. Agentic AI Engineer
3. Applied AI Engineer
4. AI / ML Engineer with deployment or evaluation responsibility
5. Suitable Python Backend / Automation Engineer roles, especially those touching AI systems, observability or internal platforms

## Why this is the best portfolio strategy

- The supplied project direction transfers to pipelines, tracing, evals, tool safety and failure analysis.
- LangGraph/LangChain implementation plus measured optimization directly addresses the supplied posting.
- Security provides additional evidence when supported by working controls and bypass tests.
- Available job examples do not establish that AI hiring is easier or more accessible overall than backend hiring.

## What to say in interviews

Use one sentence:

"I build AI agent systems that are observable, testable, and safe to operate under real tool-use and prompt-injection risk."

That line is stronger than saying you are "just a backend developer" because it explains both execution and judgment.

## Scope rule

Do not try to become broad on purpose. Keep the portfolio focused on one story:

- agentic workflow
- evaluation and replay
- security controls
- incident analysis

This produces relevant interview evidence; it does not guarantee interviews or employment.
