# Career Comparison and Hiring Evidence

Research date: September 8, 2026. This small sample informs entry requirements; it is not a labor-market survey. Indexed content may be stale. A discoverable listing does not verify that applications remain open.

## Which path is easier?

**AI Agent Engineer is my recommended main preparation target for your supplied history**, because the project work transfers directly to the supplied duties. For a first security role, **SOC/security operations may be more accessible than specialist AI security** if the actual opening accepts juniors and operational work fits you. This is a conditional judgment, not a hiring-probability estimate.

| Path | Required evidence | Fit with supplied history | Main entry friction |
|---|---|---|---|
| AI Agent / Applied AI | Python service, tool use, evaluation, optimization, delivery | Strong continuity with harness/evaluation direction | Software/ML fundamentals, implementation ownership, supplied degree requirement |
| SOC / Security Operations | Logs/networks, triage, escalation | Needs new operational evidence | Shift/location constraints and actual junior eligibility |
| AppSec / Security Automation | Find, explain, repair and regression-test vulnerabilities | Reuses software/harness skills | Practical secure-code or production experience requirements |
| AI Security Engineer | Agent implementation plus security/adversarial evaluation | Coherent future specialty | Combined knowledge; sampled dedicated roles request professional experience |
| AI Security Researcher | Research methods, ML/security experiments, possibly publications | Not established by existing proposals | Separate research preparation and often advanced qualifications |

A long gap does not make any title objectively easiest. Recent inspectable work and eligible targeting are controllable. If immediate income is the main constraint, consider eligible SOC and backend/automation roles alongside AI applications rather than completing three portfolios first.

## Application decisions

For Korea, search duties as well as titles: AI agent intern, applied AI, Python AI backend, security automation, junior AppSec, security monitoring. Check degree, experience, location, shifts and conversion terms.

For Montreal, verify Canadian work authorization/sponsorship, French/English and enrollment requirements. Your eligibility for these has not been established. An ineligible internship is not a realistic lead merely because it says “intern.”

Use one main AI résumé and a separate security résumé only for that branch. After roughly 20 eligible applications, inspect the funnel: few screens suggest targeting/CV issues; failed technical screens suggest fundamentals; weak project discussions suggest insufficient evidence or ownership. This is a practical review checkpoint, not a statistically reliable threshold.
