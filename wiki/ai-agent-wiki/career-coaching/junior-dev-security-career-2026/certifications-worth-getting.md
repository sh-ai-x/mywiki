# Certifications worth getting

> **TL;DR**: Tier 1 (must-have, do before job-hunting): 정보처리기사 + 정보보안기사 + CompTIA Security+. Tier 2 (years 1–2): AWS Security Specialty, CKS, AZ-500, CCSP. Tier 3 (years 3–5, signal career direction): CISSP, OSCP, OSWE/OSP, GIAC, CISA/CISM/CRISC. Tier 4 (2026 hot): AI-security + GRC + cloud-native. Highest ROI for KR juniors: 정보처리기사 + 정보보안기사.

Certifications are higher-ROI in the security track than the SWE track. The 2026 ranking below is calibrated to **junior** status (0–3 years experience) and the Korean market.

**Tier 1 — get before job-hunting (must-have):**

| Cert | Issuer | Cost (KRW approx) | Exam | Why |
|---|---|---|---|---|
| **정보처리기사** | Q-Net (한국산업인력공단) | ~30K | Field+Practical | National cert; required or preferred at most Korean employers; pass-rate ~40-50% field / 20-30% practical ([Nature Group analysis](https://www.naturegroup.co.kr/data/board/pds/1647060767_1.pdf)) |
| **정보보안기사** | Q-Net | ~30K | Field+Practical | National cert; required for most Korean security roles; harder than 정보처리기사 |
| **CompTIA Security+** | CompTIA | ~$390 | CBT | Global baseline; recognized at every multinational in Korea; good on a junior resume |

**Tier 2 — first 1–2 years on the job:**

| Cert | Issuer | Cost | Why |
|---|---|---|---|
| **AWS Certified Security — Specialty** | AWS | $300 | Cloud-security specialty; required at any cloud-heavy employer ([AWS page](https://aws.amazon.com/certification/certified-security-specialty/)) |
| **CKS (Certified Kubernetes Security Specialist)** | CNCF | $395 | K8s security; high-value at platform-security roles ([CNCF page](https://www.cncf.io/certification/cks/)) |
| **Azure Security Engineer Associate (AZ-500)** | Microsoft | $165 | Azure cloud security ([Microsoft page](https://learn.microsoft.com/en-us/credentials/certifications/azure-security-engineer/)) |
| **CCSP (Certified Cloud Security Professional)** | (ISC)² | ~$600 | Global cloud-security cert; pairs with CISSP for senior tracks |

**Tier 3 — 3–5 years (signals career direction):**

| Cert | Issuer | Notes |
|---|---|---|
| **CISSP** | (ISC)² | Requires 5 years experience (or 4 years + degree). Junior cannot take it but should plan for it. [ISC² page](https://www.isc2.org/certifications/cissp). KR pass rate ~15-25% ([해커스잡](https://www.hackersjob.com/cissp/합격률)) |
| **OSCP** | Offensive Security | 24-hour practical exam. The red-team signal. KR pass rate ~30-40% ([해커스잡](https://www.hackersjob.com/oscp/합격률)). [OffSec page](https://www.offensive-security.com/pwk-oscp-ine/) |
| **OSWE / OSEP** | Offensive Security | Web-app / advanced exploit specialty; for senior red-team track |
| **GPEN / GXPN** | SANS / GIAC | Premium-tier; expensive; signals serious red-team commitment |
| **CISA / CISM / CRISC** | ISACA | Audit / GRC / risk-management track |

**Tier 4 — 2026 hot / new:**

- **AI-security certifications** — emerging 2026. SANS SECAIR, ISO/IEC 42001 lead auditor, NIST AI RMF Foundation, OWASP AI Security & Privacy Guide training. None have KR market dominance yet; **being early is itself the differentiator**.
- **GRC certifications** — PECB ISO/IEC 42001 Lead Auditor, CIPP/E (privacy), CIPP/US. Korean financial-sector demand for GRC is growing fast.
- **Cloud-native security** — eBPF-based tooling (Cilium Tetragon, Falco), service mesh security (Istio, Linkerd). Cert landscape is fragmented; a strong GitHub project demonstrating the skills is more valuable than a cert.

**Cert ROI ranking for KR juniors (2026):**

1. 정보처리기사 (KRW 30K → 5–10M salary bump over 3 years)
2. 정보보안기사 (KRW 30K → 5–10M, mandatory at most security roles)
3. AWS Security Specialty (USD 300 → 10–15M bump; fast ROI)
4. CompTIA Security+ (USD 390 → 3–5M; global baseline)
5. CKS (USD 395 → 5–8M; k8s-heavy employers)
6. OSCP (USD 1,600+ → 15–25M bump if red-team path; long ROI)
7. CISSP (USD 749 → 10–20M bump; requires 5 years experience)

The cost-benefit for OSCP/CISSP is delayed because of the experience requirement — start preparing for OSCP in year 1, CISSP in year 4.
