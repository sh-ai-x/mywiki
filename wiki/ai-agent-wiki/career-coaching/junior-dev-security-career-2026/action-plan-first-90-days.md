# Action plan — first 90 days

> **TL;DR**: Week 1–2 inventory + signal setup (portfolio, LinkedIn, resume). Week 3–4 application engine (30–50 targeted apps + 20 warm intros). Week 5–8 interview loop (LeetCode + system design + behavioral + portfolio walkthrough). Week 9–12 decision + close. Single highest-ROI move: polish the dev-harness-kit portfolio, because every hour compounds across all applications.

A concrete week-by-week checklist for a junior SWE or junior security pro entering the 2026-Q3 market.

**Week 1–2 — Inventory + signal setup.**

- [ ] Finalize the GitHub portfolio: dev-harness-kit README polished, every skill documented, eval-set passing, security-review skill runs end-to-end.
- [ ] LinkedIn profile: headline is *specific* ("Junior SWE specializing in TDD + AI-eval + security-aware engineering" or "Junior Security Pro specializing in ISMS-P + AI-security + CTF"); banner + featured project = dev-harness-kit.
- [ ] Korean resume (1 page, PDF): tailored per role; portfolio link under "Selected Work" with the security framing or SWE framing from [[resume-portfolio-dev-harness-kit|Resume / portfolio positioning]].
- [ ] Portfolio link tested from incognito: anyone with the link can clone + install + run + see the eval pass-rate.

**Week 3–4 — Application engine.**

- [ ] Apply to 30–50 targeted roles (not 200 cold applications): 10 대기업, 15 중견, 10 startup, 5 public-sector/consulting. Each application tailored (different resume paragraph, role-specific 자기소개서).
- [ ] Reach out to 20 people for warm intros: alumni from your university, ex-coworkers, anyone 1-degree from a target company. Aim for 5 referrals.
- [ ] Track every application in a spreadsheet: company, role, posting URL, contact, applied-date, status, next-action. The discipline matters; without it, follow-ups die.

**Week 5–8 — Interview loop.**

- [ ] Daily: 2 LeetCode problems (alternating topic: arrays/strings, trees/graphs, DP, SQL). Use AI assistance; practice the "explain the AI's choice" discipline.
- [ ] Daily: 1 system-design problem (write the API, the schema, the failure modes; 30 minutes timed).
- [ ] 3x/week: behavioral STAR rehearsal (record yourself; review for clarity, specificity, numbers).
- [ ] Once/week: portfolio walkthrough rehearsal (15 minutes; show the dev-harness-kit to a friend who knows nothing about it; check for clarity).
- [ ] For security track: 2 CTF problems/week from pwn.college or HackTheBox; write up the solution in a short blog post.

**Week 9–12 — Decision + close.**

- [ ] Compare offers on the same dimensions: base, bonus structure, RSUs/options (with vesting schedule + exercise window), learning opportunities (rotation, conferences, cert reimbursement), work-life balance, team fit.
- [ ] Negotiate: in Korea, base-salary negotiation is constrained (~5–15% range); bonus and sign-on are more flexible. For startups, equity negotiation has more room.
- [ ] Accept, decline, and follow-up: every interviewer who invested time gets a personal thank-you note; every rejected application is logged for the post-mortem.

**Adjacent work — ongoing:**

- **Cert prep:** if you don't have 정보처리기사 / 정보보안기사 yet, the 90-day plan is *in addition to* a cert-prep block of 5 hours/week. Target: 정보처리기사 by week 12 (assuming a field exam in that window); CompTIA Security+ by week 8.
- **CTF participation:** enter Codegate CTF 2027 preliminary when registration opens; participate in weekly online CTFs in the meantime.
- **OSS contribution:** one merged PR to a public OSS project (even a doc fix) by week 12.
- **AI-fluency maintenance:** one new Claude Code / Codex skill added to the dev-harness-kit every month; published as a release.

**The single highest-ROI move in the 90-day plan:**

> **The dev-harness-kit portfolio is the differentiator.** Every hour spent polishing the README, tightening the eval suite, adding a new skill, or running a structured review on the existing code is an hour that compounds across all 30–50 applications. Cold-applying with a generic resume is the lowest-ROI activity; warm intros + a strong portfolio + a tight funnel is the highest. The 90-day plan is structured to maximize the latter.
